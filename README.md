# Student-Performance-Analysis using Python
## Overview
This project analyses student performance data using Python.
## Tools Used
- **Python**
- **Pandas**
- **Matplotlib**
- **Jupyter Notebook**
## Features 
- Data loading 
- Statistical analysis
- Total marks calculation
- Average marks calculation
- Student ranking
- Data visualisation
